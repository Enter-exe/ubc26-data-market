# Working on the UBC26 demo

Prioritize seller commitments, verifiable sample selection, and buyer-only delivery. Keep the agent's valuation and API interface small. Use testnet funds for development.

Use the available Superpowers workflow skills and Ponytail for coding. Assign independent implementation or review tasks to subagents when useful. For UI work, use Impeccable and browser verification. Review the combined changes before pushing. Cloud environments may have different skills installed. Circle’s official [Arc integration skill](https://github.com/circlefin/skills/blob/master/plugins/circle/skills/use-arc/SKILL.md) and [Arc documentation](https://docs.arc.io/arc/references/connect-to-arc) describe chain configuration.
